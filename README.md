# Rebound — Blade & Sorcery Mod

Throw any item, press grip on an empty hand, and it flies back to you Mjolnir-style — arcing overhead, orienting handle-first, and landing right in your grip.

## Building

1. Copy `.env.example` to `.env` and set your game path:
   ```
   GAME_FOLDER=C:\Program Files (x86)\Steam\steamapps\common\Blade & Sorcery
   ```
2. Run `build.bat` — output lands in `Rebound/`
3. Copy the `Rebound/` folder into your mods directory:
   ```
   <game>\BladeAndSorcery_Data\StreamingAssets\Mods\
   ```
